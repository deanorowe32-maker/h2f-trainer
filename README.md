# H2F Trainer

Holistic Health and Fitness (H2F) trainer for Soldiers: weekly PT plans, AFT scoring, injury rehab by body map, sleep, nutrition, mind and spirit tracking, and fictional ribbons earned for consistency. Works offline and installs to your home screen.

- **Train:** build a weekly PT plan, run workouts with a timer, and score your AFT.
- **Rehab:** tap where it hurts on the body map and get a phased PT plan, even for more than one injury at a time.
- **Readiness:** log sleep, meals, water, mood and reflections, with trends and evidence-based tips.
- **Ribbons:** earn 76 fictional ribbons for real habits, with stars each time you earn one again.
- **Unit:** send a weekly summary code to your squad leader, and leaders can roll up their whole unit. No accounts and no server are needed.

Your data stays on your phone. It works offline, and it installs like an app from the browser.

## Deploy

This is a static site with no build step. On Vercel: Add New → Project → import this repo → Deploy, with every setting left as it is.
